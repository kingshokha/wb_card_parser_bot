# Telegram-бот для парсинга и создания карточек товаров Wildberries

Бот позволяет отправлять ссылку или артикул любого товара с Wildberries, после чего парсит его данные (название, описание, габариты, категорию, фото) и автоматически создает готовую карточку в вашем кабинете продавца через официальный **WB Content API**.

---

## 📁 Структура проекта

* `start.bat` — Единый исполняемый файл для двойного клика и быстрой сборки/запуска хоста.
* `bot.py` — Главный файл запуска Telegram-бота (`aiogram 3`).
* `wb_parser.py` — Модуль парсинга карточек-доноров с Wildberries.
* `wb_api.py` — Модуль работы с официальным API Контента Wildberries (`content-api.wildberries.ru`).
* `config.py` — Загрузка конфигураций и токенов из `.env`.
* `.env` — Файл настроек с вашими токенами (не передавать третьим лицам!).
* `requirements.txt` — Список зависимостей Python.

---

## 🚀 Быстрый запуск

### Вариант 1: Через единый кликабельный файл `start.bat` (Рекомендуется)
Просто дважды кликните по файлу **`start.bat`** в папке проекта. Файл сам проверит зависимости и запустит бота на локальном хосте.

### Вариант 2: Запуск через консоль

1. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка токенов (`.env`)**:
   Укажите `BOT_TOKEN` и `WB_SELLER_TOKEN` в файле `.env`.

3. **Запуск сервера бота**:
   ```bash
   python bot.py
   ```

## 📱 Использование
1. **Создание карточки**: Отправьте ссылку на товар Wildberries (например: `https://www.wildberries.ru/catalog/12345678/detail.aspx`).
2. **Просмотр характеристик товара**: Напишите **«Характеристики карточки»** или командами `/charcs` / `/charcs [артикул]`. Бот попросит артикул или сразу выведет полный детальный список всех характеристик.

## 📝 История изменений (Changelog)

### v3.3.0 (Команда просмотров характеристик `/charcs`)
- **Просмотр характеристик по команде**: Добавлена команда `/charcs` (а также текстовые триггеры *«Характеристики карточки»*, *«Характеристики»*). 
- **Интерактивный ввод артикула**: При вызове без артикула бот запрашивает артикул через FSM и выводит структурированный список всех спарсенных параметров товара.

### v3.2.0 (Защита от сетевых сбоев Telegram `TelegramNetworkError`)
- **Автоматические повторы при сетевых сбоях**: Внедрены безопасные функции-обертки `safe_reply` и `safe_edit_text`. При временном разрыве соединения со шлюзом Telegram (`api.telegram.org:443`) или сбросе сокета бот автоматически повторяет попытку отправки без падения или зависания хэндлера.

### v3.1.0 (Поддержка передачи «Вес с упаковкой» в `dimensions.weightBrutto`)
- **Автоматическое извлечение веса**: Реализован парсинг веса товара с упаковкой из характеристик донора.
- **Официальный формат `weightBrutto`**: Согласно официальной спецификации WB Content API, вес упаковки теперь автоматически переводится в килограммы и передается в специальный объект `dimensions.weightBrutto` (`{"length": L, "width": W, "height": H, "weightBrutto": 2.7}`), исключая ошибки при валидации карточки.

### v3.0.0 (Поддержка числовых скаляров `charcType == 4` по разъяснению WB API Staff)
- **Передача числовых скаляров**: В соответствии с официальным разъяснением WB API Staff, характеристики с `charcType == 4` передаются в виде одного чистого скалярного числа (например, `"value": 60` вместо массива `[60]`), а текстовые единицы измерения (`дБ`, `м/с`) не добавляются, т.к. определены в `unitName`.
- **Корректная обработка `maxCount`**: Для `charcType == 1` параметр `maxCount == 0` трактуется как отсутствие лимита элементов массива, а `charcType == 0` — как отключенное поле.

### v2.2.0 (Файл быстрого запуска `start.bat`)
- **Единый скрипт запуска**: Создан файл `start.bat` для быстрого запуска локального сервера бота в один клик с автоматической установкой зависимостей.

### v2.1.0 (Отчет о пропущенных характеристиках с `maxCount == 0`)
- **Прозрачный отчет в Telegram**: В итоговое сообщение отчета добавлен блок с перечнем всех характеристик, которые были пропущены из-за ограничения `maxCount = 0` на стороне API WB.
- **Подсказка для ручного ввода**: Указаны имена и значения исходных свойств донора (например, *Скорость воздушного потока: 150 м/с*), чтобы продавец мог при необходимости указать их вручную в личном кабинете.

### v2.0.0 (Фильтрация депрецированных характеристик `maxCount == 0`)
- **Исключение невалидных характеристик**: В справочнике Wildberries ряд характеристик имеет значение `maxCount: 0` (например, `Максимальный уровень звука/шума`, `Скорость воздушного потока` для категории Воздуходувки). Передача любых значений в такие поля вызывает ошибки валидатора WB.
- **Полное устранение ошибок в черновиках**: В `map_characteristics` добавлена автоматическая отбраковка характеристик с `maxCount == 0`, что гарантирует создание карточек со 100% валидными данными.

### v1.9.0 (Продление тайм-аута ожидания индексации и живой статус)
- **Продление тайм-аута до 90 секунд**: Время ожидания регистрации `nmID` новой карточки серверами WB увеличено с 30 до 90 секунд (30 попыток по 3 сек). Загрузка фотографий гарантированно выполняется даже в моменты высокой нагрузки на серверы WB.
- **Динамический прогресс в Telegram**: Бот транслирует текущие попытки ожидания индексации в исходное сообщение Telegram, информируя пользователя о ходе привязки фото.

### v1.8.0 (Снятие лимитов на количество фото — до 30 штук)
- **Полная загрузка всех галерей**: Сняты внутренние искусственные лимиты парсинга (`range(1, 15)`) и загрузки (`[:10]`). Парсер и API выгрузки теперь считывают и привязывают к карточке до **30 фотографий** (максимальный лимит Wildberries API).

### v1.7.0 (Расширенный параллельный сканер CDN `basket-01` .. `basket-80`)
- **Поддержка 9- и 10-значных новейших артикулов**: Wildberries распределяет новые артикулы (например `889477504`, `1152950095`) по новым корзинным серверам CDN (`basket-39`, `basket-43` и выше). 
- **Параллельное асинхронное сканирование**: Реализован параллельный запрос по диапазону серверов `basket-01` .. `basket-80`, что обеспечивает мгновенное извлечение данных товаров любых категорий и диапазонов артикулов без задержек.

### v1.6.0 (Гарантия уникальности SKU и точный фильтр `withPhoto: -1`)
- **Гарантированно уникальный `vendorCode`**: Добавлена динамическая метка времени к артикулу продавца, чтобы исключить ошибки дублирования SKU при повторном создании товаров.
- **Фильтр поиска карточек без фото**: В `get_card_nmid_by_vendor_code` явно передан параметр `"withPhoto": -1`, гарантирующий корректное обнаружение свежесозданных нолей-черновиков для выгрузки фотографий.

### v1.5.0 (Строгое сопоставление nmID и предотвращение чужих фото)
- **Строгая валидация `vendorCode`**: Функция `get_card_nmid_by_vendor_code` теперь осуществляет **исключительно точное (1-в-1)** сравнение артикулов продавца. Исключён фоллбэк на чужие/старые карточки из кабинета.

### v1.4.0 (Перезапись сообщений и загрузка медиафайлов)
- **Перезапись сообщений**: Первоначальный статус-ответ от бота теперь не плодит новые сообщения, а перезаписывается (редактируется по месту) на всех этапах работы до формирования итогового отчета.
- **Прямая загрузка фотографий**: Реализована автоматическая выгрузка оригиналов изображений с CDN донора и отправка бинарных байт файлов через `POST /content/v3/media/file` с заголовками `X-Nm-Id` и `X-Photo-Number`.

### v1.3.0 (Улучшение извлечения артикулов и логирования)
- **Точное извлечение артикулов**: Усовершенствован регулярный поиск артикулов из ссылок любых форматов (WB catalog, product URL, query params), исключающий подмену товара.
- **Подтверждение артикула в Telegram**: В предпросмотр сообщения бота добавлены артикул WB и точное название спарсенного товара.

### v1.2.0 (Исправление ошибок валидации WB)
- **Габариты и вес**: Данные о длине, ширине, высоте и весе теперь не передаются отдельными элементами в массиве `characteristics`, а строго упаковываются в специальный объект `dimensions` (`length`, `width`, `height`).
- **Числовые характеристики (`charcType == 4`)**: Все числовые характеристики автоматически очищаются от текста и передаются строгими числами `int`/`float`, а не строками.

### v1.1.0 (Обновление требований пользователя)
- **Артикул продавца**: Генерация короткого латинского SKU из первых слов названия товара.
- **Поле "Бренд"**: Всегда передается пустым (`""`).
- **Парсинг характеристик**: Реализовано автоматическое сопоставление опций донора с официальным справочником категорий WB Content API (`/content/v2/object/charcs/{subjectID}`).

### v1.0.0 (Релиз)
- Парсинг карточек-доноров через прямые JSON CDN Wildberries.
- Создание карточек и привязка медиа (фото) через официальный WB Content API.
